# Claude AI Development Course

Repository containing my notes, exercises, examples, and implementations developed while completing a course on **Claude AI and the Anthropic API**.

The course focuses on integrating Claude into software applications and covers topics ranging from API fundamentals and prompt engineering to RAG, tool use, MCP, Claude Code, and AI agent architectures.

This repository serves as a **portfolio and study record** of my progress learning Claude AI and modern AI application development.

The implementations here are primarily intended to demonstrate what I practiced and learned throughout the course.
